A local educational project designed to **educate** users — family members, friends, or colleagues — about the dangers of the web. It includes a credential theft simulation and a malicious link click simulation, showing in real time which data the browser shares automatically.

> ⚠️ **ETHICAL AND LEGAL DISCLAIMER**  
> This project is purely for **educational and defensive** purposes. It is not affiliated with Amazon, Microsoft, or any other brand.  
> Credentials and data entered **are not sent to any external or third-party server**: they are logged exclusively locally, on your computer, to show the user how easy it is for a website to track their actions.  
> **Do not use this code for illegal purposes or to deceive people without their knowledge.** Use the demo only with people who have given explicit consent.

## ✨ Features

| File / Component | Description |
|---|---|
| **`demo-login.html`** | An e-commerce-style login page that shows how entered data travels to the server. It includes real-time field validation, such as password requirements, and redirects to the official website at the end of the fake procedure. |
| **`click.html`** | A page that simulates a virus alert. It shows the user — and you — how much information their browser shares automatically just by opening a link, via fingerprinting. |
| **`server.py`** | A lightweight multithreaded Python HTTP server that serves the pages, intercepts the data, prints it readably in the terminal, and also saves it to a local `log.txt` file. |

## 🛠️ Prerequisites

- **Python 3.8** or higher.
- *(Optional)* **Cloudflare `cloudflared`**, if you want to expose the demo on the internet securely via an HTTPS tunnel.

## 💻 Installation and Setup

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-user/your-repo.git
   cd your-repo
   ```

2. **Add your logo — important for visual appearance:**

   To avoid copyright issues and ensure the repository is not mistaken for a real phishing site, no official logos are included.

   If you want `demo-login.html` to display a logo instead of a broken image icon, place a file named **`logo.png`** directly in the project root folder.

3. **Start the local server:**

   ```bash
   python3 server.py
   ```

   On Windows, if `python3` is not available, you can use:

   ```bash
   python server.py
   ```

   The terminal will show the local IP address.

4. **Open the demos in your browser:**

   - Login simulation: [http://localhost:8000/demo-login.html](http://localhost:8000/demo-login.html)
   - Click simulation: [http://localhost:8000/click.html](http://localhost:8000/click.html)

## 🌍 Expose the Demo Online with Cloudflare Tunnel

If you want to send the link to someone who is not on the same Wi-Fi network, for example on 5G, you can use Cloudflare Quick Tunnel. It is free and does not require an account.

Leave the server running and open a second terminal:

```bash
cloudflared tunnel --url http://localhost:8000
```

Copy the `https://...trycloudflare.com` link that appears and add `/demo-login.html` or `/click.html` to let the person access the desired demo.

> ⚠️ Expose the demo online only if necessary and always with the consent of the people involved. Do not collect real credentials.

## 🧹 Cleanup and Privacy

During the demo, the server saves all received data in the `log.txt` file in the same project folder. This file **is not uploaded to GitHub** thanks to the `.gitignore` file.

To avoid leaving sensitive data, such as real credentials typed by mistake, delete the file after finishing the demo with:

```bash
rm log.txt
```

On Windows:

```powershell
del log.txt
```
